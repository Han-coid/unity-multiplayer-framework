## Windows 独立进程验证内容

1. Host + Client 在 loopback UDP 上建立连接。
2. 双方实际观察到远端玩家生成、位置变化和 Ready 状态。
3. Client 主动退出后重新加入，再次观察到同步。
4. 满员房间返回 `ROOM_FULL`。
5. 错误游戏 ID 返回 `INCOMPATIBLE_GAME`。
6. 无本地玩家的 Server + 两个 Client 正常同步。
7. Host 关闭后，Client 收到断线原因并进入 Faulted。
8. 连接未监听的端口在设定期限后超时。

每个成功测试进程会写入 `[SMOKE] PASS` 并以退出码 `0` 结束。日志中的故意拒绝连接 / 超时警告属于预期分支。
